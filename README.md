# ApplyHub

Staj ve iş başvurularını ekleyebileceğin, düzenleyebileceğin, silebileceğin ve durumlarına göre filtreleyebileceğin bir uygulama. Kayıtlar tarayıcıdaki LocalStorage'da saklanır.

Kullanılan teknolojiler: React, Vite ve CSS.

Kullanmak için: [tnc-applyhub.vercel.app](https://tnc-applyhub.vercel.app/)
